How it works

One request. One route. One report.

The process stays simple so a busy property manager knows exactly what is being covered.

01 · REQUEST

Send the property.

Property address, visit type, requested timing, access information, and anything specific you want documented.

02 · CONFIRM

Scope before the visit.

We confirm the agreed areas, timing, starting price, and report expectations in writing.

03 · FIELD VISIT

Follow the route.

Each agreed area is photographed and recorded as No item noted, Item noted, or N/A. A noted item receives a short factual line and photo.

04 · REVIEW

Joe checks the draft.

The report is compared with the photos and entered facts before it leaves On-Site Property Support.

05 · DELIVERY

Manager-ready PDF.

The finished report is sent to the agreed contact.

If minor work is requested: Document → separate proposal → written approval → work → invoice. A field walk never authorizes work automatically.
